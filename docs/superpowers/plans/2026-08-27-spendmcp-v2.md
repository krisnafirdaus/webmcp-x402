## Amendments — advisory pass 2 (2026-08-27, binding on Tasks 6+)

License is now **Apache-2.0** (LICENSE + NOTICE committed; matches x402's own license; challenge requires a clearly detectable OSS license). WebMCP Leverage is the first tie-breaker between equally-scored entries — when trading scope, protect the WebMCP surface first.

1. **Tool inputs are strict JSON Schema** (T11): every inputSchema gets `additionalProperties: false`; IDs pattern-validated (`^q_[a-z0-9]+$`, `^pay_[a-zA-Z0-9_-]{8,128}$`, resource ids `^[a-z0-9-]{1,64}$`); strings get `maxLength`; no arbitrary URLs and no recipient/amount/asset parameters on any tool — payment details always resolve server-side from quoteId (prompt-injection can then at worst buy an allowlisted resource within policy).
2. **Idempotency naming aligns with x402's payment-identifier extension** (T9/T11/T13): the client-generated idempotency value is called `paymentId` in the tool surface (`purchase_access(quoteId, resourceId, paymentId)`, generated `pay_<crypto-random>` client-side when the agent omits it), sent as `X-Payment-Identifier` header; server keys the replay map on it. Server's internal record id stays `nextId('pay')` — return BOTH (`receipt.paymentId` = server record id, `receipt.clientPaymentId` = idempotency value) or simplify by using the client value as THE paymentId when present (implementer picks one, documents it, tests pin it).
3. **Read-only tools carry annotations** (T11): `annotations: { readOnlyHint: true }` on discover/preview/get_quote/get_spending_policy/list_unlocked/get_payment_receipt; `untrustedContentHint: true` on tools returning dataset/publisher content (preview, query_premium_dataset). Annotations are agent hints, never security enforcement.
4. **AbortSignal** (T11): tool `execute(args, context?)` — if the host passes an AbortSignal, forward it to fetch for read-only tools. `purchase_access` ignores abort after signing and, when the outcome is unknown, returns an honest `{ status: 'settlement_pending', paymentId, message: 'check status before retrying' }` instead of a generic error. Never invent a new paymentId on retry.
5. **Server-side spend guard** (T9): client policy is UX, not security. The purchase route additionally enforces a per-IP in-memory daily guard in demo mode (default: max 25 purchases and $2.00/day per IP; 429 with structured body beyond). Trivial token-bucket map, documented as demo-grade.
6. **Payment record carries an explicit status** (T9): `status: 'settled' | 'delivered' | 'failed'` — set 'settled' after settle(), 'delivered' after the data grant is returned; receipts expose it. Full 13-state machine is documented as future work in THREAT_MODEL, not built.
7. **WebMCP-absent fallback labels** (T12): badge shows `WebMCP available` / `Manual browser mode`; app fully usable manually. Feature-detect `navigator.modelContext ?? document.modelContext` (spec is a CG report, hosts differ).

13. **Purchase-route contract** (from Task 8 security review; binding on T9): (a) ATOMIC QUOTE CONSUME — before any await/settle, do a synchronous check-and-set on `quote.consumedBy` (read → if set, `releaseNonce(nonce)` + return quote_consumed → else set to a pending id) with NO await between read and write; this is the only barrier between two concurrent valid payments and a quote double-spend (verify's nonce check straddles an await and cannot serialize this). (c) Never JSON.stringify anything holding `ipSpend.atomicTotal` (bigint throws) — stringify explicitly. export interface ModelContextTool {
```ts
  name: string
  description: string
  inputSchema: Record<string, unknown>
  execute(args: Record<string, unknown>): Promise<{ content: Array<{ type: 'text'; text: string }> }>
}

export interface ModelContext {
  registerTool(tool: ModelContextTool): unknown
}

/** ChatGPT's in-app browser and Chrome may expose the API on different globals. */
export function getModelContext(): ModelContext | null {
  const g = globalThis as Record<string, any>
  return g.navigator?.modelContext ?? g.document?.modelContext ?? null
}

export interface ToolRegistrar {
  /** Registers unless the name is already registered or mc is null. Returns whether it registered. */
  register(tool: ModelContextTool): boolean
  names(): string[]
}

/**
 * Tracks registered names (hosts may not dedupe) and optionally mirrors
 * execute fns into `bag` so tests/e2e can drive tools without a WebMCP host.
 */
export function createToolRegistrar(
  mc: ModelContext | null,
  bag?: Record<string, (args: Record<string, unknown>) => Promise<unknown>>,
): ToolRegistrar {
  const registered = new Set<string>()
  return {
    register(tool) {
      if (!mc || registered.has(tool.name)) return false
      mc.registerTool(tool)
      registered.add(tool.name)
      if (bag) bag[tool.name] = (args) => tool.execute(args)
      return true
    },
    names() {
      return [...registered]
    },
  }
}
```

```ts
export const bySlugOrId = (id: string) => RESOURCES.find((r) => r.id === id) ?? null
export const priceUsdOf = (r: Resource) => Number(r.priceAtomic) / 1_000_000
export async function resourceHash(r: Resource): Promise<string> {
  const bytes = new TextEncoder().encode(JSON.stringify(r.fullData))
  const digest = await crypto.subtle.digest('SHA-256', bytes)
  return `sha256:${Array.from(new Uint8Array(digest), (b) => b.toString(16).padStart(2, '0')).join('')}`
}
export function queryRows(r: Resource, q: { metric?: string; from?: string; to?: string }) {
  const rows = r.fullData.filter((row) =>
    (!q.metric || row.metric === q.metric) && (!q.from || row.month >= q.from) && (!q.to || row.month <= q.to))
  const values = rows.map((x) => x.value)
  const summary = {
    count: rows.length,
    min: values.length ? Math.min(...values) : null,
    max: values.length ? Math.max(...values) : null,
    avg: values.length ? Number((values.reduce((a, b) => a + b, 0) / values.length).toFixed(2)) : null,
    first: rows[0] ?? null, last: rows.at(-1) ?? null,
  }
  return { rows, summary }
}
```

```ts
import { bySlugOrId } from './resources'
import { nextId, stores, type Quote } from './store'
import { NETWORK, PAY_TO, QUOTE_TTL_MS, USDC } from './x402'

export function issueQuote(resourceId: string): Quote | null {
  const r = bySlugOrId(resourceId)
  if (!r || r.priceAtomic === '0') return null
  const quoteId = nextId('q')
  const now = Date.now()
  const quote: Quote = {
    quoteId,
    resourceId: r.id,
    issuedAt: now,
    expiresAt: now + QUOTE_TTL_MS,
    requirements: {
      scheme: 'exact',
      network: NETWORK,
      maxAmountRequired: r.priceAtomic,
      resource: `/api/purchase/${quoteId}`,
      description: `Access to ${r.title} (${r.provider})`,
      mimeType: 'application/json',
      payTo: PAY_TO,
      asset: USDC,
      maxTimeoutSeconds: 300,
      extra: { name: 'USDC', version: '2' },
    },
  }
  stores().quotes.set(quoteId, quote)

}

  if (quote.consumedBy) return { ok: false, error: 'quote_consumed' }
  return { ok: true, quote }
```

```ts
import { verifyTypedData } from 'viem'
import { chainIdFor, decodePaymentHeader, EIP3009_TYPES, type PaymentRequirements } from 'webmcp-x402'
import { stores } from './store'

export type VerifyResult =
  | { ok: true; payer: `0x${string}`; nonce: `0x${string}` }
  | { ok: false; error: 'bad_header' | 'bad_signature' | 'wrong_recipient' | 'underpaid' | 'expired' | 'nonce_replayed' }

export async function verifyPayment(header: string, req: PaymentRequirements): Promise<VerifyResult> {
  let payload: ReturnType<typeof decodePaymentHeader>
  try {
    payload = decodePaymentHeader(header)
    if (payload.x402Version !== 1 || payload.scheme !== 'exact') return { ok: false, error: 'bad_header' }
  } catch {
    return { ok: false, error: 'bad_header' }
  }
  const { authorization: auth, signature } = payload.payload
  if (auth.to.toLowerCase() !== req.payTo.toLowerCase()) return { ok: false, error: 'wrong_recipient' }
  if (BigInt(auth.value) < BigInt(req.maxAmountRequired)) return { ok: false, error: 'underpaid' }
  const now = BigInt(Math.floor(Date.now() / 1000))
  if (now < BigInt(auth.validAfter) || now > BigInt(auth.validBefore)) return { ok: false, error: 'expired' }
  if (stores().nonces.has(auth.nonce)) return { ok: false, error: 'nonce_replayed' }
  const valid = await verifyTypedData({
    address: auth.from,
    domain: {
      name: req.extra?.name ?? 'USDC',
      version: req.extra?.version ?? '2',
      chainId: chainIdFor(payload.network),
      verifyingContract: req.asset,
    },
    types: EIP3009_TYPES,
    primaryType: 'TransferWithAuthorization',
    message: {
      from: auth.from, to: auth.to, value: BigInt(auth.value),
      validAfter: BigInt(auth.validAfter), validBefore: BigInt(auth.validBefore), nonce: auth.nonce,
    },
    signature,
  }).catch(() => false)
  if (!valid) return { ok: false, error: 'bad_signature' }
  stores().nonces.add(auth.nonce)
  return { ok: true, payer: auth.from, nonce: auth.nonce }
}
```

```ts
import { NextRequest, NextResponse } from 'next/server'
import { bySlugOrId, resourceHash } from '@/lib/resources'
import { validateQuote } from '@/lib/quotes'
import { verifyPayment } from '@/lib/verify'
import { settle } from '@/lib/settle'
import { nextId, stores, type PaymentRecord } from '@/lib/store'

function receiptOf(p: PaymentRecord) {
  return {
    paymentId: p.paymentId, quoteId: p.quoteId, resourceId: p.resourceId,
    resourceHash: p.resourceHash, amountAtomic: p.amountAtomic,
    amountUsd: Number(p.amountAtomic) / 1_000_000,
    payer: p.payer, recipient: p.recipient, nonce: p.nonce,
    idempotencyKey: p.idempotencyKey,
    settlement: { mode: p.mode, txHash: p.txHash ?? null },
    issuedAt: p.issuedAt,
  }
}

export async function GET(req: NextRequest, ctx: { params: Promise<{ quoteId: string }> }) {
  const { quoteId } = await ctx.params
  const idempotencyKey = req.headers.get('X-Idempotency-Key') ?? ''

  // Idempotent replay: same key returns the original receipt + grant, no re-charge.
  const existingId = idempotencyKey ? stores().byIdempotency.get(idempotencyKey) : undefined
  if (existingId) {
    const p = stores().payments.get(existingId)!
    const r = bySlugOrId(p.resourceId)!
    return NextResponse.json(
      { granted: true, replayed: true, receipt: receiptOf(p), data: { rows: r.fullData, metrics: r.metrics } },
      { headers: { 'X-PAYMENT-RESPONSE': Buffer.from(JSON.stringify({ success: true, replayed: true, mode: p.mode, nonce: p.nonce, txHash: p.txHash ?? null })).toString('base64') } },
    )
  }

  const check = validateQuote(quoteId)
  if (!check.ok) return NextResponse.json({ error: check.error }, { status: 410 })
  const { quote } = check
  const resource = bySlugOrId(quote.resourceId)!

  const header = req.headers.get('X-PAYMENT')
  if (!header) {
    return NextResponse.json(
      { x402Version: 1, accepts: [quote.requirements], error: 'payment required' },
      { status: 402 },
    )
  }
  const verified = await verifyPayment(header, quote.requirements)
  if (!verified.ok) {
    return NextResponse.json(
      { x402Version: 1, accepts: [quote.requirements], error: verified.error },
      { status: 402 },
    )
  }

  let outcome
  try {
    outcome = await settle(header, quote.requirements)
  } catch {
    stores().nonces.delete(verified.nonce) // settlement failed; free the nonce
    return NextResponse.json(
      { x402Version: 1, accepts: [quote.requirements], error: 'settlement_failed' },
      { status: 402 },
    )
  }

  const record: PaymentRecord = {
    paymentId: nextId('pay'),
    quoteId: quote.quoteId,
    resourceId: resource.id,
    resourceHash: await resourceHash(resource),
    amountAtomic: quote.requirements.maxAmountRequired,
    payer: verified.payer,
    recipient: quote.requirements.payTo,
    nonce: verified.nonce,
    idempotencyKey: idempotencyKey || verified.nonce,
    mode: outcome.mode,
    txHash: outcome.txHash,
    issuedAt: new Date().toISOString(),
  }
  quote.consumedBy = record.paymentId
  stores().payments.set(record.paymentId, record)
  stores().byIdempotency.set(record.idempotencyKey, record.paymentId)

  return NextResponse.json(
    { granted: true, replayed: false, receipt: receiptOf(record), data: { rows: resource.fullData, metrics: resource.metrics } },
    { headers: { 'X-PAYMENT-RESPONSE': Buffer.from(JSON.stringify({ success: true, mode: record.mode, nonce: record.nonce, txHash: record.txHash ?? null })).toString('base64') } },
  )
}
```

```ts
import { createBudget, type Budget } from 'webmcp-x402'

export interface PolicyState {
  perTxCapUsd: number
  sessionCapUsd: number
  spentUsd: number
  autoApproveUnderUsd: number
  allowedNetworks: string[]
}
export type PolicyRefusal = 'per_tx_cap_exceeded' | 'session_budget_exceeded' | 'network_not_allowed'
export type PolicyCheck = { allowed: true; needsConfirm: boolean } | { allowed: false; reason: PolicyRefusal }

export interface Policy {
  readonly state: PolicyState
  readonly budget: Budget
  check(q: { priceUsd: number; network: string }): PolicyCheck
  /** Human edits: applied as given (floors at spent handled by budget). */
  humanSet(p: Partial<Pick<PolicyState, 'perTxCapUsd' | 'sessionCapUsd' | 'autoApproveUnderUsd'>>): void
  /** Agent edits: lowering free; raising clamped to human-approved values. */
  agentSet(p: Partial<Pick<PolicyState, 'perTxCapUsd' | 'sessionCapUsd' | 'autoApproveUnderUsd'>>): void
  setAutoApprove(underUsd: number): void
}

export function createPolicy(init?: Partial<PolicyState>): Policy {
  let perTxCapUsd = init?.perTxCapUsd ?? 0.05
  let humanPerTxCapUsd = perTxCapUsd
  const allowedNetworks = init?.allowedNetworks ?? ['base-sepolia']
  const budget = createBudget({
    capUsd: init?.sessionCapUsd ?? 0.2,
    autoApproveUnderUsd: init?.autoApproveUnderUsd ?? 0.05,
    spentUsd: init?.spentUsd ?? 0,
  })
  let humanSessionCapUsd = budget.state.capUsd

  return {
    get state() {
      const b = budget.state
      return {
        perTxCapUsd,
        sessionCapUsd: b.capUsd,
        spentUsd: b.spentUsd,
        autoApproveUnderUsd: b.autoApproveUnderUsd,
        allowedNetworks: [...allowedNetworks],
      }
    },
    budget,
    check({ priceUsd, network }) {
      if (!allowedNetworks.includes(network)) return { allowed: false, reason: 'network_not_allowed' }
      if (priceUsd > perTxCapUsd + 1e-9) return { allowed: false, reason: 'per_tx_cap_exceeded' }
      const decision = budget.decide(priceUsd)
      if (decision === 'deny') return { allowed: false, reason: 'session_budget_exceeded' }
      return { allowed: true, needsConfirm: decision === 'confirm' }
    },
    humanSet(p) {
      if (p.perTxCapUsd !== undefined) { perTxCapUsd = p.perTxCapUsd; humanPerTxCapUsd = p.perTxCapUsd }
      if (p.sessionCapUsd !== undefined) { budget.setCap(p.sessionCapUsd); humanSessionCapUsd = budget.state.capUsd }
      if (p.autoApproveUnderUsd !== undefined) budget.setAutoApprove(p.autoApproveUnderUsd)
    },
    agentSet(p) {
      if (p.perTxCapUsd !== undefined) perTxCapUsd = Math.min(p.perTxCapUsd, humanPerTxCapUsd)
      if (p.sessionCapUsd !== undefined) budget.setCap(Math.min(p.sessionCapUsd, humanSessionCapUsd))
      if (p.autoApproveUnderUsd !== undefined) budget.setAutoApprove(Math.min(p.autoApproveUnderUsd, humanPerTxCapUsd))
    },
    setAutoApprove(underUsd) {
      budget.setAutoApprove(underUsd)
    },
  }
}
```
